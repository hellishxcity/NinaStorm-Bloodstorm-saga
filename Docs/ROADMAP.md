# NinaStorm: The Bloodstorm — Roadmap

## Milestone 1: Graybox prototype
- [x] Create starter health, movement, melee, enemy and Blood Magic scripts.
- [x] Add a primitive-based environment builder for the Ashen Marches.
- [ ] Open in Unity and resolve any editor-version-specific issues.
- [ ] Verify ground collision, camera follow and character movement.
- [ ] Add touch joystick and action HUD.

## Milestone 2: First playable mission — The Queen Beneath the Chapel
- [ ] Intro sequence: Nina awakens in the flooded crypt.
- [ ] Teach movement, dodge, attacks and Blood Essence.
- [ ] Three Ashen Knights and the Hollow Knight boss.
- [ ] Escape route to the village and meet Sable.
- [ ] Equip Devil's Tongue and unlock the first story quest.

## Milestone 3: Combat quality
- [ ] Light/heavy attacks, combo timing and aerial follow-ups.
- [ ] Dodge invulnerability windows, parries, counters and stagger.
- [ ] Enemy telegraphs, hit reactions and boss phases.
- [ ] Finishers, loot drops, XP and kill-based healing.
- [ ] Blood Essence costs, cooldowns, status effects and boss resistance.

## Milestone 4: The Red Queendom
- [ ] Throne room, armory, wardrobe, Blood Forge and merchants.
- [ ] Servant NPCs and training chamber.
- [ ] Story and Free Roam portals.
- [ ] Sanctuary upgrades, vault inventory and raid-defense events.
- [ ] Save/load and persistent progression.

## Milestone 5: World and content
- [ ] Region discovery, map and quest/bounty tracking.
- [ ] Ashen Borderlands, Drowned Marches, Ironwood Frontier, Gloamfen and later regions.
- [ ] Unique bosses and weapon rewards.
- [ ] Replace all graybox geometry with authored optimized assets.

## Milestone 6: Android readiness
- [ ] Touch controls and readable mobile UI.
- [ ] Performance profiling on low- and mid-range devices.
- [ ] Accessibility, save integrity and device-resume handling.
- [ ] Playtesting, bug fixing and signed Android build.

## Scope note
A complete open-world RPG is a large project. Build one polished, playable mission first, then expand. Current code is a prototype foundation, not a complete game, and has not been compiled or tested in Unity yet.
